# 실제 시장 자율 채팅 관찰 — 2026-11-15

**결과: 이번 한 장에서는 자율적인 싸움·중재가 발생하지 않았다. 기능 검증 실패이며, 싸움 대화를 생성된 것처럼 제시하지 않는다.**

## 실행 조건과 범위

- 저장된 `Assets/Scenes 1/TradeScene.unity`를 실제 Unity Play Mode로 실행했다. 간이 시장, 대체 봇 클래스 또는 고정 포트폴리오를 사용하지 않았다.
- 기존 시장 시드 12345, 실제 봇 1,191개, 거래 900초·장 마감 후 20초 설정을 그대로 사용했다. 게임 1일 개장부터 결산을 거쳐 2일 개장 직후 종료했다.
- `Time.timeScale=1`, `Time.captureDeltaTime=0`. 실제 시장 실행 약 15분 21초, 실행기 준비·종료 포함 약 16분 3초다. 배속이나 고정 시간 간격 가속을 사용하지 않았다.
- 시작 화면의 기본 확인 버튼만 실행했다. 그 버튼에 원래 연결된 NPC 리딩방 가입 요청 외에 플레이어 매매·리딩방 지시·회유·강퇴는 없었다.
- 봇 감정·성격·자금·방 배정·발화·답변 확률·중재 성공률을 주입하거나 조정하지 않았다. 관찰기는 기존 사건 및 메시지를 읽어 기록한다.
- 화면 렌더링을 끄고 최대 20FPS, CPU affinity 1개 논리 코어, BelowNormal 우선순위, Unity 작업 스레드 1개로 실행했다. 다른 검증은 동시에 실행하지 않았다.
- 최대 Unity 메모리 2,006MiB. 오류 0, 실제 시장 무결성 실패 없음, 프로세스 종료 코드 0. 종료 코드 0은 관찰 실행이 완료됐다는 뜻이며 싸움·중재 기능 통과를 뜻하지 않는다.
- 실행 전후 씬 및 채팅 JSON 해시가 일치한다. 시장·봇 운영 코드는 이번에 변경하지 않았다.
- 첫 샌드박스 실행은 라이선스 IPC 연결 단계에서 막혀 중단했고, 시장이나 채팅이 시작되지 않았다. 정상 권한으로 실행한 `run-02`만 실제 시장 관찰 자료다.

## 후속 수정이 필요한 지점

`InvestorSociety.SocialAdvance`는 .25초마다 24개 봇을 순회한다. 약 1,190개 사회 참여 봇을 한 번 순회하는 데 명목상 약 12.5초가 걸린다. 실제 응답의 대기 허용 시간은 30초이며 방별 발화 제한은 10초에 2건이다. 우선순위 정렬은 해당 처리 묶음의 준비된 의도에만 적용된다. 다른 묶음에 있는 응답이 기다리는 동안 새 체결·감정 발화가 방의 발화 한도를 소비할 가능성이 있다.

이것은 **코드와 실측 응답 누락에서 도출한 원인 후보**다. 이번 관찰기는 모든 내부 대기 의도의 만료 경로를 추적하지 않았으므로 45건 모두를 같은 원인이라고 확정하지 않는다. 다음 수정 우선순위는 실제 봇 수에서 응답 처리 지연과 발화 제한의 관계를 재현하고, 감정·발화 확률을 바꾸지 않은 채 대화 대기열이 제대로 처리되는지 검증하는 것이다.
