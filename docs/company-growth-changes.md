# 내 기업 성장 → 비상장 평가 → 상장 → 시장 거래

2026-11-16 작업. 기존 3D 태블릿의 **경영 → 내 기업 → 성장·상장**에 연결했다. 씬, 카메라, 모니터·태블릿 위치와 기존 거래 엔진은 유지한다. 새 화면은 기존 태블릿 컨트롤 Sprite와 TMP SDF, 한국어·영어·일본어 String Table을 사용한다.

## 플레이 흐름

- 새 게임: 개인 현금 5천만 원을 유지하며, 평가액 2천만 원인 비상장 기업 지분 10,000주를 100% 소유한다. 기업의 최초 운영 현금은 160만 원이다. 개인 현금과 기업 현금은 분리한다.
- `설비 확장`: 기초 생산 매출 증가. `영업 확대`: 수요 증가. `기술 연구`: 변동비 감소. 실제 기업 현금으로 투자하며, 기본 완공 기간은 2일, 각 부문 최대 5단계이다. 화면에 다음 단계 효과·비용·기간을 표시한다.
- 기존 배당·재투자·비축 정책과 함께 적용한다. 실적은 장 마감 때 결산한다. 기업 배당을 기존 정산 보고서에 지급하며, 새 기업을 가진 플레이어에게 이전 고정 사업수입 25만 원을 중복 지급하지 않는다.
- 비상장 기업은 종목 선택 목록·주문 대상에서 제외한다. 대시보드 보유 자산에는 `비상장`과 `평가`를 표시하며, 기업 정보의 시총 칸 대신 기업 평가액을 보여준다.
- 기본 상장 조건: **평가액 5천만 원 이상, 흑자 결산 누적 3회 이상, 사업 확장 완료 2회 이상, 미지급 비용 0원**. 조건을 충족하면 직접 신청한다. 신청만으로 당일 거래가 시작되지는 않는다.
- 다음 개장 때 조건과 실제 인수 자금을 다시 검사한다. 거래소가 기존 발행량의 25%만큼 신주를 실제 현금으로 인수한다. 10,000주인 창업 기업은 12,500주가 되며, 창업자 80%·신규 유통분 20%가 된다. 공모대금은 기업에 들어간다. 인수 자금이 없으면 대기하며 주식을 발행하지 않는다.
- 상장 후 기존 봇·거래소·호가·차트에 연결한다. 공식 상장·사업 확장 기사는 기존 뉴스 시스템을 거친다. 현재 시장 가격을 성장 버튼이나 뉴스가 임의로 올리지는 않는다. 마감 시총은 실제 종가 × 발행 주식 수이다.

## 자산 계산과 대표 경영자

기업 평가액은 초기 자본 + 출자금 + 누적 유보이익 + 평활 순이익 변화에 대한 배수로 계산한다. 적자는 평가액을 낮추며, 투자 버튼을 누른 순간 가짜 매출이나 수익을 지급하지 않는다. 사업 확장과 실제 실적이 평가액에 반영된다.

출자는 개인 현금에서 기업 현금으로 옮긴다. 해당 지분의 취득원가도 증가시켜 단순 출자를 평가이익으로 잘못 계산하지 않는다. 상장 전 완전 소유 기업에 대해 그 지분을 가진 계좌로 출자할 수 있다. 개인의 주문 예약금·세금 채무는 출자 가능한 현금에서 제외한다.

각 기존 기업 소유주 `WhaleBot`을 대표 경영자로 재사용한다. 대표들은 하루 한 번 자신의 탐욕·공포, 기업 현금·부채·완공 상태를 보고 배당 정책과 유료 프로젝트를 선택한다. 회사별 결과는 독립적이다. 플레이어가 지배하는 회사는 대표의 자동 투자가 플레이어 설정을 덮어쓰지 않는다. 대표가 없는 동적 기업에는 대표 봇을 배정한다. 비상장 NPC 기업도 성장 조건을 충족하면 자체 상장을 신청한다.

## 주요 변경 위치

- `CompanyGrowth.cs`: 성장 설정, 유료 프로젝트, 완공, 이익 기반 평가, IPO 조건.
- `CorporateEconomy.Growth.cs`: 창업 기업, 출자·투자·상장 API, 대표의 일별 결정, 유한 현금 신주 인수.
- `CompanyGrowthUI.cs`, `CompanyDashboardUI.cs`: 기존 태블릿 기업 페이지와 성장 화면. 출자 입력창에 독립 Viewport·마스크를 적용해 언어 변경 시 숫자 잘림을 방지한다.
- `StockManager.Economy.cs`: 새 게임의 비상장 창업, 거래 가능한 종목과 분리, 승인된 IPO 등록, 복원된 종목 재연결.
- `CompanyBusiness.cs`, `CorporateEconomy.cs`: 매출·수요·연구 원가 반영, 비상장 결산. 생산성 상한에서 효과 없는 자동 재투자 비용이 빠지던 문제도 수정했다.
- `Trader.cs`: 출자 원가 보정과 실제 현금 신주 인수. 기존 시장 주문·체결 계산은 유지한다.
- `MarketDayController.cs`: 비상장 주주 원장 검사, 다음 개장 상장 처리. 잔고·배당의 가벼운 반복문은 고정 프레임 대기 대신 약 2ms 처리 예산으로 분할한다.
- `SessionStore.cs`: 저장에만 존재하는 기업의 정체성·참조 복원. 초기 개장 코루틴이 복원된 시간을 덮어쓰지 않도록 종료한다.
- `CandleHistoryManager`, `StockInterestManager`, `ExchangeBot`, `MarketRhythmDirector`, `NpcLeadingRoom`, `PlayerProgression`, `WorldDramaDirector`: 저장된 상장 종목의 기존 데이터를 유지하면서 런타임 체결 구독을 중복 없이 다시 연결한다.
- `DailyIncomeController`, `SystemMenuUI`, `InvestmentPositionRow`, `PlayerCompanySetupUI`, `ItCompanyManager`: 고정 수입 중복 방지, 비상장 결산·보유 표시, 시작 안내, 뉴스가 성장된 실제 기업 가치를 초기값으로 덮어쓰는 문제 방지.
- `Assets/Resources/Progression/CompanyGrowth.json`: 위 기본 조건·비용·성장 효과를 변경할 수 있는 설정.
- `Assets/Localization/Import/DonDon.csv`, `Assets/Resources/Localization/SourceIndex.json`, Unity Localization Tables: 새 기능의 3개 언어 번역.

## 저장 호환성

기존 개인 투자자 저장에서는 `PLAYER` 주식이 이미 상장되고 외부로 배분되어 있었다. 이를 회수하거나 임의로 상장 폐지하지 않는다. 실제로 소유하는 기업이 없으면 기존 명목 사업을 `PLAYER_BIZ` 비상장 기업으로 연결하고, 과거 결산일을 소급 지급하지 않는다. 이미 저장한 신규 창업 기업·진행 중 프로젝트·평가·상장 신청·발행량은 그대로 복원한다.

구독 재연결은 새 주식을 다시 발행하거나 가격·차트 기록을 초기화하지 않는다. 저장 및 복원 시점에만 수행하며 매 프레임 리플렉션이나 전체 UI 재생성을 추가하지 않았다.

## 검증 기록

자동 수치 검사: 성장 21개, 기존 기업 회귀 16개, 일별 수입·세금 회귀 271개 통과. 전체 런타임·Editor C# 컴파일 성공; 기존 사용 중단 API 등의 경고는 남아 있다.

실제 Unity 검증은 CPU 코어 1개, BelowNormal, 20fps, 메모리 4GiB 상한으로 하나씩 실행했다. 전체를 한 프로세스에서 실행한 초기 검증은 시간·메모리 상한으로 종료되어 **전체 통과로 계산하지 않았다**. 실제로 생성된 5일째 체크포인트를 새 프로세스에서 이어받아 상장과 복원을 분리 검증한다. 테스트에서만 장 경계를 이동하며 게임에는 배속 기능을 넣지 않는다.

- `Validation/Settings/CompanyGrowth02`: 실제 1~5일 결산, 설비·영업 완공, 대표 자율 결정, IPO 조건·원장 검사. 이후 복원 메모리 상한으로 종료.
- `Validation/Settings/CompanyListing02`: 상장·봇 실제 체결·첫 상장일 결산·저장, 3개 언어 입력 표시 및 레이아웃 **21개 검사 통과**. 67.2초, 최대 3,642MiB.
- `Validation/Settings/CompanyRestore01`: 상장 후 재실행, 8개 관찰자의 체결 이벤트 단일 연결, 기존 캔들 유지, 중복 배당 방지, 기존 저장의 비상장 기업 연결, 저장에만 존재하는 기업 복원 **19개 검사 통과**. 48.8초, 최대 3,245MiB.
- `Validation/Settings/CompanyVisual01`: 복원 뒤 레이아웃이 반영된 프레임에서 최종 촬영. 3개 언어의 입력값·활성 텍스트 **10개 검사 통과**. 44.6초, 최대 2,730MiB. 원시 입력 문자열뿐 아니라 실제 게임 카메라의 숫자 표시도 확인했다.
- 최종 실제 게임 카메라 이미지: `Validation/Settings/CompanyVisual01/growth-{ko,en,ja}-{1600x900,1920x1080}.png`. 상장 후 기업 정보: `Validation/Settings/CompanyListing02/listed-company-1920x1080.png`.

## 남은 범위

이번 단계는 기존 태블릿으로 실제 투자·성장·상장까지 플레이 가능한 기업 경영이다. 공장 건물을 직접 배치하는 3D 건설 시스템이나 업종별 제품 생산망을 추가하지 않았다. 업종별 수요 주기와 각 대표 심리를 재사용한다.

기본 수치는 조정 가능한 첫 기준이다. 수십~수백 일 연속 시장 플레이에서 기업 가치·배당·NPC 확장 속도와 메모리 사용량의 장기 균형은 추가 검증이 필요하다. 이번 결과를 장시간 연속 운용 안정성 검증으로 확대 해석하면 안 된다.

신규 C# 전문과 여러 군데 바뀐 파일의 함수별 원본·수정본은 `docs/company-growth-code.md`에 별도로 제공한다.
