# 채팅 사회화 결정 기록

기준: `chat-social-spec.md` 전체, 2026-11-15. 아래 단계 표시는 변경할 단계이며, 완료 여부는 진행 기록과 해당 커밋으로 확인한다. 조사 단계에서는 게임 코드를 바꾸지 않았다.

## D01 — 신뢰·배신 상한 예외 (사용자 확정)

기존 의도: 100% 초과 신뢰·배신과 부드러운 과열 맥동. 명세 3장 기본 범위와 충돌하여 0장의 중단 규칙에 따라 질문했다. 사용자가 2번을 선택했다.

- 신뢰도·배신감 실제 값은 100을 넘어갈 수 있으며 기존 맥동 연출을 유지한다.
- 명세 6~9장의 확률·배율에 입력하는 신뢰·배신은 `min(값, 100)`으로 제한한다. 100 초과분에 새 효과를 만들지 않는다.
- 4분면 및 히스테리시스 판정은 실제 값을 사용한다.
- 분노 0~100, 호감 -100~100, 탐욕·공포·경각심·위축 0~100은 명세대로 유지한다.
- 1단계에 범위/스냅샷 계약, 4~6단계에 소비 계산과 경계 테스트를 적용한다. 사용자 답변으로 중단 사유가 해소되었다.

## 나머지 충돌과 처리

- D02 (6단계): 기존 FOMO 수치·원형 게이지를 지속 시간 태그로 교체한다. 구형 사회 스냅샷의 수치는 버리며 투자 전략 클래스 이름 FomoBot 자체는 삭제하지 않는다.
- D03 (6단계): 선형 수락식과 동일 목표 매도 대신 4분면별 수락·투자 비율·목표·손절을 기존 명령 실행기에 연결한다.
- D04 (4단계): 부정 소문 목격의 배신감 상승을 제거한다. 간접 경험은 제한된 신뢰 변화, 직접 경험만 배신에 영향을 준다.
- D05 (3단계): 문자열 닉네임 호출과 즉시 독립 응답을 targetId/replyTo/thread 및 지연 응답으로 바꾼다. 표시 이름은 ID에서 가져온다.
- D06 (2~3단계): MarketDay/Society/Conversation의 병렬 문장 생성 경로를 기존 Society의 단일 동기→화행→사실→말투 과정으로 연결한다. 기존 문구를 데이터로 이관하고 최근 키 제한을 적용한다.
- D07 (전 단계): NPC 입문방 4는 기존 진행 흐름을 위해 보존한다. 플레이어 조치는 자기 방 1~3에만 허용한다. 기존 UI·풀링·스크롤을 재사용한다.
- D08 (1/6단계): 금융 경험 원장과 8개 현저성 발화 기억은 목적이 다르다. 원장은 보존하고 제한 기억을 추가한다.
- D09 (7단계): 기존 관심 분배 패치 상태에서 실제 3일 시장 기준선을 측정한다. A→측정→필요 시 B→C→D 순으로 적용한다. 단순 난수 선택 결과를 체결 지표로 대체하지 않는다.
- D10 (1단계): 현재 저장은 PlayerProgression v1 조각과 키 설정뿐이다. 이들을 변경하지 않고 버전 있는 사회 상태 어댑터를 추가한다. 존재하지 않는 전체 월드 저장을 호환 확인했다고 주장하지 않는다.
- D11 (1~4단계): 기존 장 시간·1배속·일시정지 보존. 게임 분과 스케일된 현실 초를 별도로 주입한다. 추가 성격 생성은 독립 난수 스트림을 써서 기존 RNG 소비 순서를 바꾸지 않는다.
- D12 (6단계): 기존 거래소 AI의 신뢰>배신 비교도 4분면에 맞게 갱신한다. 외부 소비자를 남겨 서로 다른 판정을 하지 않는다.
- D13 (6단계): 9.2의 적대/무관심 이탈은 `RELATIONSHIP_DEPARTURE`로 별도 기록한다. 7장의 분노 퇴장(`VOLUNTARY_EXIT`)과 원인이 다르므로 1→2→3→4 단계 이력을 만들어 붙이지 않는다. T3/R5는 분노 퇴장에 적용하며 관계 이탈도 로그에서 누락하지 않는다. 공용방 활동과 실제 계좌는 유지한다.
- D14 (6단계): 새 스레드가 성립하기 전에도 실제 공격 발언으로 분노가 3단계가 될 수 있다. 방장 제재는 최근 실제 공격 발언과 상대 관계도 확인하여 이 상황을 무관한 봇의 임의 추방으로 잘못 분류하지 않는다.
- D15 (7단계): 기존 급관심은 별도 표시 목록이 아니라 공용 대화의 종목 선택 확률이었다. 이 저장소를 재사용하고 상위 3개를 체류 판정용 급관심 집합으로 삼는다(`hotListCount`). 기존 60현실초/120초 창을 5게임분/180게임분으로 교체한다. 장중에만 네 지표를 집계하며 30분 거래량 창은 각 장 첫 30분 이후부터 측정한다. 기준선과 수정 후에 같은 기준을 적용한다. 밤의 비거래 시간을 임의의 1위 체류로 세지 않는다.

## 8단계 세부 적용

- D16: 문구의 말끝 장식은 메시지 ID·봇 ID로 만든 별도 결정적 난수를 사용한다. 사회 판단이나 거래 난수를 소비하지 않는다. 원래 템플릿 키·후보 수·순서·사실 조건을 유지하여 문장 개선과 R 지표 튜닝을 분리했다. 응답 문맥 변형은 같은 화행 안에서만 선택하고 `debug.contextKey`에 남긴다. 최근 키 제한과 기억 사실 검사는 그대로 적용한다.
- D17: 10.4의 예고는 `promisedAction` 메타데이터로 명시한 문구에만 연결한다. 다음 해당 종목 판단에서 매수 또는 매도 확률을 2배(최대1)로 한 번 적용하고 기존 계좌/예약금/호가/리딩 명령의 제약을 통과해야 주문할 수 있다. 종목 거래 불가·자산 부족은 이유를 기록하고 취소한다. 현재 기본 문구는 확인된 거래·보유·관찰을 말하며 확정적인 미래 매매 예고를 추가하지 않았다. 예고용 문구를 주입한 테스트에서는 발화→대기 상태→일회 확률 적용·저장 복원을 검증했다. 기본 문구에서 예고가 실제 발생했다고 주장하지 않는다.
- D18: 13.1 개발 도구는 F9로 검사 모드를 켠 뒤 기존 메시지/닉네임 버튼을 누르는 방식이다. 일반 플레이의 프로필·제재 연결은 유지한다. 정식 빌드에서는 패널/입력 폴링을 제외하며 감정·사건 로그는 계속 기록한다. 고정 시드 재시작은 현재 세션을 초기화하지만 기존 영구 저장을 삭제하지 않는다.
- D19: 장기 실행에서는 종료 스레드 작업 캐시를 512개 기준으로 정리한다. 최근 표시 메시지·대기 응답·퇴장 예약에서 참조하는 항목은 보호하며 원본 사건 로그와 봇의 현저성 기억은 삭제하지 않는다. 24시간 기준 테스트의 전체 스레드 수는 이 한도보다 작아 R2를 부분 표본으로 바꾸지 않는다. 장마감 누적 분석은 디스크 사건 로그를 기준으로 해야 한다.

## 저장소

4단계 반영 확인: D04의 기존 Witness 간접 배신 증가를 신뢰 감소/하루 상한/사건 중복 제한으로 교체했다. D11의 1배속 시계/유예 시간은 유지한다. 분노 퇴장을 우회하던 지루함 퇴장은 새 사회 경로에서 비활성화한다. 4분면 이탈은 6단계에 별도 원인으로 다룬다. R4는 기준 리딩방 언쟁만 집계하고 공용방 후속 언쟁은 별도 보고한다. T 검사는 모든 방을 포함한다.

시작 시 Git 저장소가 없었다. 로컬 저장소를 초기화하고 변경 대상 소스·설정의 기존 상태를 기준 커밋으로 남긴다. 생성 캐시와 이전 Validation 출력은 제외한다. 외부 원격 저장소와 푸시는 만들지 않는다.

## 후속 사용자 요청: 커뮤니티 말투·중재·알림 (2026-11-15)

- D20: 사용자 요청에 따라 기존 격식(polite/rough)과 독립적인 `진지함`/`진지하지 않음` 성향을 추가했다. 저장 버전 1/2 및 기존 여섯 성격값은 유지한다. 빠진 성향만 시드로 보충하고 새로운 성향·문구 선택으로 기존 사회/거래 난수 스트림을 소비하지 않는다. 신뢰/배신의 100 초과 예외는 그대로다.
- D21: 수익 대화의 숫자 슬롯만 한국어 구어체로 바꾼다. `500만 정도`/`500장`/`500 정도`, `50퍼`/`50%`를 지원하되 `장`은 만 원 단위로 고정한다. 사실 메타데이터, 계산, 주가·주문 수량·지정가와 예고/신호는 변경하지 않는다. 새 커뮤니티 문구는 기존 화행·사실 검증 이후 별도 문구층에서 선택하며 기억·제재·미래 주문 약속을 임의로 대체하지 않는다.
- D22: 닉네임 강조는 TMP mark로 표시하는 UI 전용 처리다. 원문·로그는 유지하고 실제 명단의 가장 긴 이름을 매칭한다. 전체 봇을 매 프레임 검색하지 않으며 명단 트리와 표시 문자열을 캐시한다. 같은 문자열로 높이를 측정하고 방 전환·오래된 메시지 제거에 맞춰 캐시를 정리한다.
- D23: 사용자가 제시한 중재 거절→항변/도발→퇴장→남은 상대 반응을 구현한다. 고정 대본이 아니라 목격·성격·관계·스트레스와 실제 퇴장 사건으로 판단한다. 차분한 목격자는 중재를 우선하고, 스트레스 80 이상은 10~50%로 6~10초 후 퇴장할 수 있다. 기존 실제 리딩방 이탈/주문 취소 훅을 사용한다. 공용방은 대화만 쉬고 거래는 지속한다. 스트레스 퇴장도 자진 퇴장 집계에 포함하고 같은 언쟁의 연쇄 당사자 퇴장을 막는다. 종료한 언쟁에 새 참여자를 예약하던 결함도 수정했다.
- D24: 입장·퇴장·강퇴/제재는 명시적 `ChatRoomNotice` 유형으로 표시한다. 봇의 일반 발언이나 시장 뉴스를 문장 내용으로 추측해서 시스템 알림으로 바꾸지 않는다. 기존 풀에서 가운데 배경 띠와 텍스트만 사용하고 프로필 클릭은 비활성화한다. 강퇴 시 일반 퇴장 알림을 중복 발행하지 않는다.
- D25: 퇴장 후 반응 기본 확률 .60→.35를 적용했다. 침묵할 때 추가 판단 난수를 소비하지 않는 사건별 난수로 분리했다. 중재 성공률 .3→.4 및 기존 퇴장 유예30→40초 실험은 통과하지 않아 원복했다. R1~R8의 범위는 그대로 두고 고정5시드 재검증을 통과했다. 전후 값·실패/성공 출력과 실제 생성 원문은 `Validation/ChatVoice`, 적용/코드 보고서는 `docs/chat-voice-changes.md` 및 `docs/chat-voice-code.md`에 남겼다.

## 후속 사용자 요청: 말투 확장·대화 주제·종목 링크·입력 중 (2026-11-15)

- D26: 사용자가 읽고 답하지 않는 흐름을 허용했다. 이번 작업에서는 응답 확률, 언쟁/중재 확률 또는 R 합격 범위를 조정하지 않는다. 실제 시장에서 응답률이 낮았던 이전 관측 결과를 성공한 대화로 고쳐 제시하지 않는다.
- D27: 주제 세 개는 금지 상한이 아니라 방별 선호다. 최근 발화 점수를 감쇠시키고 상위 세 주제에 가중치를 주며, 평범한 새 주제를 한 번 망설이게 한다. 실제 급등락 목격·리딩 명령/성과·진행 중 답변은 망설임을 우회한다. 기존 MarketConversationFocus의 실제 거래·가격 정보를 대화 선택에만 재사용한다. 거래 엔진과 주가를 바꾸어 채팅 집중도를 맞추지 않는다.
- D28: 여섯 고유 말투와 264개 새 문구는 사실/화행 검증 이후 별도 표현층에 추가한다. 기존 진지함/진지하지 않음 확률과 모든 기존 설정값·문구를 보존한다. 말투 배정은 기존 저장 ID·성격으로 안정적으로 산출하며 별도 저장 스키마나 거래 난수 소비를 추가하지 않는다.
- D29: 입력 중은 실제 게시 대상으로 선택된 발화 의도의 대기 상태다. UI 장식 타이머나 전체 봇 의도 개수를 보여주지 않는다. 기존 주기에서 방당 최대 4명만 관리하고 실제 게시 시 현재 사실·소속·음소거·만료를 다시 검사한다. 대기 의도는 기존 임시 의도와 마찬가지로 영구 저장 대상이 아니다.
- D30: 종목명/티커 강조는 원문을 바꾸지 않는 TMP 링크다. 기존 선택 경로·World Space 이벤트 카메라·가상 행 풀을 재사용한다. 닉네임은 기존 강조/프로필을 유지하며 사용자가 쓴 TMP 링크는 실행하지 않는다. 메시지 본문의 press/click을 같은 오브젝트가 받게 하고 드래그는 ScrollRect에 전달한다.
