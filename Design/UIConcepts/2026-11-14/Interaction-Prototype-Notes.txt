DonDon 태블릿·휴대폰 조작 시안
작성일: 2026-11-14

범위
2차 시안의 자산/주문, 사건/상세, 전화 구조를 유지하는 브라우저 조작 시안이다.
Unity Assets, 씬, 프리팹, 시장·봇·주문 로직은 이 작업에서 변경하지 않았다.
금액·체결·사건·전화는 예시 데이터이며 실제 게임과 연결되지 않는다.
Unity와 시장 시뮬레이션을 실행하지 않았고 배속 기능을 추가하지 않았다.

반영한 평가
01: 주문 유형=지정가, 분할 횟수/실제 초 간격/각 회차 수량, 최종 확인과 제출 분리.
    예산·호가 단위·보유 수량 검증, 가격 수정에 따른 예상 자산 갱신.
    접수/부분 체결/완료/취소/거절 결과와 원인 표시.
    현재가를 가장 크게, 평가손익을 한 단계 작게 표시. 미니 차트에 전일 기준 추가.
    '관망 중' 대신 주문의 미제출/진행 상태를 구분.
02: 선택 표시와 시장 급변/내 포지션 관련 표시를 구분.
    매수 주도 비중의 분모·집계 기간·주도 측 의미를 명시.
    사건에서 주문 화면으로 이동해도 작성 중 입력 유지.
    실제 예시 체결 기록은 개별 체결마다 추가.
    기업 경영에는 보유 100주 표시 목표와 실제 지분 조건을 구분.
03: 신원 미확인 하나를 우선 표시하고 발신 정보는 펼쳐 보기로 이동.
    받기/거절/화면 닫기 구분. 닫아도 52초 수신 기한은 유지.
공통: 사건과 전화가 동시에 들어와도 작성 중 화면과 주문 확인을 강제로 바꾸지 않음.
      상태 저장의 지연된 자기 응답이 새 입력이나 초기화를 덮어쓰지 않도록 처리.

검증
interaction-verification.json: PASS, 78개 확인 항목(반복 초기화 및 화면 폭 검사 포함).
 - 예산 초과, 정수 수량, 호가 단위, 가격 수정, 최종 확인 전 자산 불변.
 - 전체/부분 체결, 미체결 취소, 취소 후 추가 체결 없음.
 - 3회 분할이 실제 3초 간격으로 실행되고 각각 기록됨.
 - 제출 거절 후 명시적 재시도, 지정가 대기 후 조건 충족, 보유량 초과 매도 차단.
 - 동시 사건/전화, 화면 닫기 후 수신 유지, 수신 기한 유지, 거절/받기, Esc.
 - 1280/768/375/320 브라우저 폭에서 세 화면의 수평 넘침 없음.
 - 해당 폭에서 표시되는 버튼의 높이 44px 이상.
 - 지연된 자기 상태 응답에 의한 초기화 취소 방지, JavaScript 오류 없음.
preview-verification.json: PASS, 최종 문구/포커스 변경 뒤 8개 확인 항목.
 - 1024/375 폭에서 호스트 프레임이 시안의 전체 높이를 수용.
 - 375 폭의 분할 주문에서도 하단 확인 버튼 표시.
 - 선택 사건의 43% 값과 설명 사이에 이전 사건의 58% 잔존 없음.
 - 기본 키보드 포커스와 커서 처리, 실행 오류 없음.
직접 캡처 검토: 기본 주문, 분할 주문, 사건 상세, 전화, 좁은 화면의 주문 전체.

자원 제한
브라우저 한 개를 순차 실행했고 실행 프로세스는 BelowNormal 및 CPU affinity 3으로 제한했다.
각 검증은 완료/실패 모두 finally에서 테스트 브라우저를 닫는다.
시장 장시간 검증, 병렬 Unity 실행, 렌더링 부하 테스트는 수행하지 않았다.

검증의 한계
자동 마우스 조작 검사이며 사용자 대상 사용성 테스트를 대체하지 않는다.
전화 만료까지 52초를 모두 기다리는 부재중 경로는 이번 검사에 포함하지 않았다.
시안에는 수수료·시장 변동·다중 주문 큐가 없다. 게임의 체결 엔진 성능 검증이 아니다.
브라우저 폭과 버튼 크기 확인은 실제 World Space Canvas의 가독성 확인과 다르다.
태블릿의 고정 종횡비, 실제 게임 카메라/FOV/거리, 모니터 원근, 실제 TMP 폰트는
Unity 연결 단계에서 별도로 확인해야 한다. 현재 시안은 내용 높이에 따라 늘어난다.
